# Игра "Угадай число"

Простая консольная игра на языке Go. Компьютер загадывает случайное число, а игрок пытается угадать его за ограниченное количество попыток.

## Возможности игры

- Три уровня сложности: Easy, Medium и Hard.
- Подсказки «больше» и «меньше».
- Подсказки «Горячо», «Тепло», «Холодно».
- Проверка ввода: буквы, пустые строки и числа вне диапазона не расходуют попытки.
- История введённых чисел.
- Возможность сыграть ещё раз без перезапуска программы.
- Сохранение результатов игр в `results.json`.
- Цветной вывод сообщений в терминале.

## Уровни сложности

| Уровень | Диапазон чисел | Количество попыток |
|---|---|---|
| Easy | 1–50 | 15 |
| Medium | 1–100 | 10 |
| Hard | 1–200 | 5 |

## Как запустить

Для запуска необходим установленный Go.

1. Скачайте файлы проекта.
2. Откройте терминал в папке с файлом `main.go`.
3. Выполните команду:

   ```bash
   go run main.go
   ```

   
Для работы игры не требуется устанавливать дополнительные библиотеки.

## Сохранение результатов

После завершения каждой игры программа сохраняет дату, результат (победа или поражение), количество использованных попыток и выбранную сложность в файл `results.json`.
